2. Product Vision

Trusted Assets biến các component reusable thành những asset được quản lý và approve độc lập.

Thay vì review lặp lại cùng một logo, image hoặc CTA, ZBS chỉ cần review asset một lần và cho phép merchant tái sử dụng trên nhiều template.

7.1. Impact Template API: hiển thị danh sách template bị ảnh hưởng bởi 1 asset

Khi một asset bị được update version mới hoặc xoá, API này sẽ trả về danh sách các template đang sử dụng asset đó, giúp doanh nghiệp nhanh chóng xác định và cập nhật các template bị ảnh hưởng.

Trước khi chỉnh sửa hoặc ngừng sử dụng một tài sản, doanh nghiệp cần hiểu:

  • những template nào bị ảnh hưởng
  • số lượng campaigns hiện tại đang sử dụng asset
  • tác động vận hành tiềm ẩn
GET /v1/assets/{asset_id}/impacted-templates/limit=10&offset=0

Response

{
  "asset_id": "logo_123",

  "total_impacted_templates": 42,

  "templates": [

    {
      "template_id": "tpl_1001",
      "template_name": "delivery_update",
      "status": "ACTIVE",
      "last_used_at": "2026-05-20"
    },

    {
      "template_id": "tpl_1002",
      "template_name": "payment_reminder",
      "status": "ACTIVE",
      "last_used_at": "2026-05-22"
    }

  ]
}


Nếu một logo được sử dụng bởi 5.000 mẫu, việc xóa hoặc cập nhật nó một cách thiếu cân nhắc có thể gây ảnh hưởng lớn trên toàn doanh nghiệp.


7.2. Bulk Template Migration API: thay đổi tất cả các template sang asset mới

Doanh nghiệp cần có khả năng nâng cấp toàn bộ template bị ảnh hưởng sang phiên bản asset mới nhất đã được approve. 

POST /v1/assets/{asset_id}/bulk-migrate

Request

{
  "from_version": 1,
  "to_version": 2,

  "migration_scope": "ALL_ACTIVE_TEMPLATES"
}

Response

{
  "migration_job_id": "job_789",

  "total_templates": 42,

  "status": "PROCESSING" / "COMPLETED" / "FAILED"
}


Luồng Migration

                logo_v1
                ↓
                được sử dụng bởi 42 template

                Doanh nghiệp upload:
                logo_v2
                ↓
                được approve

                Doanh nghiệp thực hiện:
                Bulk Migration API
                ↓
                Hệ thống tự động cập nhật:
                42 template
                ↓
                Template hiện tại sẽ tham chiếu đến:
                logo_v2


Chiến Lược Migration Hành Vi

Migration chọn lọc Merchant tự chọn template cần cập nhật
